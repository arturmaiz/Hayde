# Flambe - Kitchen Runner

A cooking-themed endless runner game built with Flutter and the Flame game engine.

Run as a chef through an endless kitchen, dodge pots, pans, and fire bursts while collecting ingredients for points!

## Play Now

Open on your iPhone/Android: **https://arturmaiz.github.io/Hayde/**

Add to Home Screen for full-screen native app experience.

## Features

- Cartoon-style Canvas-drawn visuals (no image assets)
- Parallax scrolling kitchen background with 3 layers
- 5 obstacle types: pot, pan, fire burst, rolling pin, knife block
- 8 collectible ingredients with floating animation
- Progressive difficulty (increasing speed and spawn rates)
- Best score persistence
- Particle effects on collect and death
- Full PWA support (offline, add to home screen, splash screens)

## Tech Stack

- Flutter + Flame game engine
- All visuals drawn with Canvas primitives
- Deployed via GitHub Actions to GitHub Pages
